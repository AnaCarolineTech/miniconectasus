# 🏥 Módulo de Triagem e Auditoria - ConectaSUS (SaaS)

Este é um mini-sistema desenvolvido em PHP focado na simulação de regras de negócio em saúde pública municipal e diagnóstico de inconsistências de dados clínicos. O projeto demonstra a aplicação prática de conceitos exigidos na triagem e suporte de nível 2 de plataformas de gestão integrada.

---

## 🛠️ Tecnologias e Conceitos Implementados

* **Backend:** PHP estruturado com Programação Orientada a Objetos (POO).
* **Banco de Dados:** Simulação de consultas SQL complexas (`INNER JOIN`) compatíveis com o ecossistema MariaDB.
* **Frontend:** Interface web moderna e responsiva construída com HTML5 e Tailwind CSS.
* **Triagem & Logs:** Console automatizado para detecção e auditoria de erros de negócio em tempo real.

---

## 📋 Arquitetura do Repositório

* `index.php`: Arquivo central contendo a lógica em POO, o processamento de dados e a interface do usuário.
* `SUPPORT_BUG_REPORT.md`: Relatório de triagem técnica detalhado que simula a documentação e o escalonamento de uma falha de validação para a equipe de engenharia, respeitando padrões de SLA.

---

## 🕹️ Como Executar Localmente

1. Certifique-se de ter o **PHP** instalado em sua máquina.
2. Baixe ou clone este repositório em sua pasta de preferência.
3. Inicie o servidor interno do PHP executando o seguinte comando no terminal do projeto:
   ```bash
   php -S localhost:8000
   ```
4. Acesse o endereço `http://localhost:8000` em seu navegador de internet para visualizar o painel interativo.
